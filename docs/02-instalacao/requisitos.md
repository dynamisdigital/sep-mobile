# Manual de Instalação e Configuração

Este manual descreve os passos necessários para configurar o ambiente de desenvolvimento e executar o **sep-mobile** localmente.

## 1. Requisitos do Sistema

- Runtime correspondente à stack **JavaScript/TypeScript**.
- Gerenciador de dependências correspondente (NodeJS package.json, NodeJS package.json, NodeJS package.json).
- Acesso à internet para download de pacotes.

## 2. Instalação de Pacotes

Execute no terminal da raiz do projeto:

```bash
# Para Python
pip install -r requirements.txt
# Para NodeJS
npm install
```
